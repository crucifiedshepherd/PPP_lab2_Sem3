## Описание проекта

Программа представляет собой Telegram-бота, предназначенного для помощи пользователю в использовании простых практик для расслабления и поддержания хорошего самочувствия. Бот предоставляет медитации, дыхательные упражнения, советы по релаксации, отслеживание настроения и ежедневные аффирмации.

## Функциональные возможности

### Основной функционал

* 🧘 Гидные медитации
* 🌬 Дыхательные упражнения
* 😊 Трекер настроения
* 🌿 Советы по релаксации
* 💭 Ежедневные аффирмации

### Дополнительный функционал

* Команды `/start` и `/help`
* Удобное меню для выбора функций бота
* Логирование работы программы

## Требования к системе

* **Python:** 3.9 или выше
* **Операционная система:** Windows / macOS / Linux
* **Библиотеки:** `python-telegram-bot`

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/crucifiedshepherd/PPP_lab2_Sem3.git
cd PPP_lab2_Sem3
```

### 2. Создание виртуального окружения

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка токена бота

Токен Telegram-бота необходимо указать в файле `config.py`.

```python
BOT_TOKEN = "ваш_токен"
```

Токен необходимо хранить в безопасности.

### 5. Запуск программы

```bash
python main.py
```
